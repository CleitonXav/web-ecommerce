# web-ecommerce

Para ativar o autocompletar dos imports no VS Code para JavaScript no Windows, siga estas etapas:

# 1. Habilitar Imports Automáticos
Abra o VS Code.
Vá em Arquivo (File) > Preferências (Preferences) > Configurações (Settings).
No campo de busca, digite: javascript.suggest.autoImports.
Marque a opção "JavaScript › Suggest: Auto Imports" como true.

# Para reiniciar o VS Code no Windows, você pode fazer de várias formas:

Método 1: Atalho no Teclado 🔄
Pressione Ctrl + Shift + P para abrir a paleta de comandos.
Digite "Reload Window".
Selecione a opção "Developer: Reload Window" e pressione Enter.
Isso reinicia rapidamente o VS Code sem fechar a janela.
'''''''

# Para tornar o Git Bash o terminal padrão no VS Code no Windows, siga estes passos:

📌 Método 1: Alterar nas Configurações (GUI)
Abra o VS Code.
Pressione Ctrl + Shift + P para abrir a paleta de comandos.
Digite "Terminal: Select Default Profile" e selecione.
Escolha "Git Bash" na lista.
Agora, ao abrir um novo terminal (Ctrl + J), o Git Bash será usado.
'''''''''

# Para instalar o TypeORM versão 0.3.20 no VS Code usando o Git Bash no Windows, siga estes passos:

📌 Comando de Instalação
No terminal do VS Code (Git Bash), execute o seguinte comando:

npm install typeorm@0.3.20

📌 Certifique-se de que o projeto tem um package.json
Se o projeto não tiver um package.json, crie um com:

npm init -y

Isso garante que o TypeORM seja instalado corretamente.
